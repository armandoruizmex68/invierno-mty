# Invierno MTY

Microclima y pronóstico del invierno 2026-27 por zona para la Zona Metropolitana de Monterrey.

- App móvil (instalable como PWA): raíz de este sitio.
- Versión de escritorio: `/escritorio/`.

Generado desde el proyecto Invierno MTY. Las cifras son un modelo estadístico, no un pronóstico oficial: para alertas, consulta al SMN y a Protección Civil de Nuevo León.
